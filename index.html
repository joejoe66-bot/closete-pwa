Install CLOSETÉ

  1. Android, Chrome, or Edge. Open the browser menu and choose Install app or Add to Home screen. If this browser offers a prompt, use the Install button.
  2. iPhone or iPad. Open this site in Safari. Tap Share, then Add to Home Screen. The home-screen icon opens it standalone. Chrome and in-app browsers on iOS cannot install it.
  3. Desktop. Use the install icon in the Chrome or Edge address bar.

Offline, the app shell can open after it has been visited once. Wardrobe rows are not stored on the device. Saves, favorites, and wear logs stay disabled offline and are not queued. An update banner appears when a new service worker is waiting.
